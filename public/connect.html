Claude app

Claude on the web, desktop, or mobile.

  1. Open Claude and go to Settings → Connectors.
  2. Click Add custom connector.
  3. Name it Scarsdale Buzz, paste your connection URL https://scarsdalebuzz.com/mcp, and click Add.
  4. Click Connect, sign in with Facebook, and choose Allow access.
  5. In a new chat, make sure Scarsdale Buzz is turned on in the tools menu, then ask away.

Don't see "Add custom connector"? Your Claude plan or organization may not allow custom connectors. On Team and Enterprise plans, an owner adds it for the organization first.

Claude Code

In your terminal.

  1. Add the server: 
    claude mcp add --transport http scarsdale-buzz https://scarsdalebuzz.com/mcp
  2. Start Claude Code, run /mcp, select scarsdale-buzz, and choose Authenticate. Sign in with Facebook in the browser window that opens.

Codex

One setup covers the Codex app, CLI, and IDE extension. They share the same configuration.

  1. Add the server: 
    codex mcp add scarsdale-buzz --url https://scarsdalebuzz.com/mcp
  2. Sign in. A browser window opens. Sign in with Facebook and choose Allow access: 
    codex mcp login scarsdale-buzz
  3. In Codex, run /mcp to confirm Scarsdale Buzz is connected.

Prefer editing config? Add this to ~/.codex/config.toml, then run the login command above:

[mcp_servers.scarsdale-buzz]
url = "https://scarsdalebuzz.com/mcp"

Grok

On grok.com.

  1. Go to grok.com/connectors.
  2. Click New Connector, then choose Custom.
  3. Paste your connection URL https://scarsdalebuzz.com/mcp and click Save & Connect.
  4. Sign in with Facebook and choose Allow access.

Custom connectors may depend on your Grok plan. On Grok Business and Enterprise, a workspace admin may need to add the connector first.

Using a different agent?

Scarsdale Buzz works with any app that supports remote MCP servers, including OpenClaw, Cursor, VS Code, and Gemini CLI. Add a new MCP server with your connection URL above, and the app will open a Facebook sign-in when it connects.
